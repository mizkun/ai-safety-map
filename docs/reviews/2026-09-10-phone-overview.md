# スマホの縦向きマップとツアー導線

スマホでシナリオ名だけが大きく並び、行き着く先が画面外になる問題を修正した。初期全体図は現在を上に置き、7経路と災害・主導権の喪失・生存や回復への分岐を同じ幅の中に収める。個別シナリオと全要素も縦方向に投影する。PCは横方向を保つ。

- 接続ボタンはスマホで下、PCで右を向く。循環と抑制の記号は区別する。
- ツアーへの入口を右下のFABに移動し、ツアー中は隠す。狭い画面ではズーム操作と重ならないようにする。
- スマホの要点カードは意味のまとまりで改行する。日本語は任意の文字位置で分割せず、英語の長い語は必要に応じてハイフンで折り返す。正式名称と詳細は保持する。
- 現在のカードの下に他のカードと同程度の余白を設ける。
- 金融ルートの W4→P1 は、接続先の真上に通せる場合に小さな二重の折れを省く。他のカードを横切る場合には省略しない。

## 検証

`npm run check`：64テスト、型、lint、日英の翻訳照合、論理の点検記録の照合に合格。`npm run build` に合格。

幅291〜740pxの全体図について全ノードと全接続の保持、カードの重なり、線によるカードの横切り、下向きの接続ラベルを検証した。全シナリオの縦向き投影についてもAND・OR・合流の入力がPC版と一致することを照合した。

ブラウザーの幅320pxの埋め込み表示で、日本語・英語の全体図、金融ルートの詳細、ツアーの開始を確認した。全体図の文字切れと、詳細の英語見出しの余白不足を修正して再確認した。最終的な実機スマートフォンのGPU性能を測定したものではない。

科学的主張や発生確率は追加していない。詳細図に多くの並列条件がある場合は、スマホでも横への移動や拡大縮小が必要になる。初期全体図の配置は経路の重要度や確率を表さない。
