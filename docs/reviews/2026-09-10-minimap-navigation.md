# ツアーのミニマップとRSI合流線

2026-09-10 / Codex

ツアー本文の小さなサムネイルを外し、地図の右下へミニマップを移した。現在選んでいるシナリオの配置をそのまま使い、青い枠で画面の表示範囲を示す。クリックでその場所へ移動でき、移動とズームは既存のカメラアニメーションを使う。

スマホでは地図アイコンから開く。展開中はズームボタンを隠して重なりを防ぎ、ミニマップをタップした後は閉じて移動先を見せる。ミニマップを閉じる操作は表示だけに作用し、条件の削除や絞り込みは行わない。

ツアーの入口を青いボタンにし、右下の「経路を選ぶ」と専用のダイアログは削除した。全体図のシナリオ選択とツアーのシナリオ選択は維持する。

RSIのOR合流は、内部の研究サイクルを含む枠のない領域の端から線が始まっていた。そのため、見えるカードから合流地点までに空白があった。序列を分解してもORの選択肢であることは変わらないため、その領域の出口をRSIのカードと明示し、カードから合流線を描く。因果データのノード・接続・共同条件は変更していない。

## 確認

- `npm run check`：60テスト、型検査、lint、内容・翻訳・レビューの検査が成功。
- `npm run build`：GitHub Pages用の静的ビルドが成功。
- RSIの合流線を、全体図・制御喪失・仕事・研究の各図とPC/スマホ配置で回帰テスト。
- ミニマップ座標を、ズーム・パン・中央寄せ・地図の端で検査。ブラウザーでも表示範囲の横幅と座標が実際のスクロール・倍率と一致することを確認。
- ブラウザーの1440×900、390×844、320×568で配置を確認。日本語と英語、ミニマップの開閉、クリック移動、ズーム追従を確認。320px幅でもページの横はみ出しはない。
- スマホサイズでの確認はブラウザーの表示幅を変えた検査。実機のCPU性能やSafariのタッチ操作を計測したものではない。

SVGの縮図は本体の配置と接続パスを再利用する。別の全体図の計算や、二つ目のカード群の描画は行わない。スクロール追従はミニマップ内で更新し、静的な縮図はメモ化する。
