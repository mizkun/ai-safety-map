# 内容の点検記録

点検は[論理と根拠の点検手順](../logic-review.md)に従います。

- Markdown：調査範囲、変更理由、未解決の論点を読むための記録。
- JSON：点検した本文と依存する根拠の指紋、担当者、判断をCIで照合する記録。

`npm run review:draft -- --id=YYYY-MM-DD-short-subject` で未記入の草案を作成します。科学的な判断は自動記入されません。以前の記録を上書きせず、新しい記録を追加してください。

最初の版を過去の記録が支持しなくなっても、その判断は履歴として残します。CIは現在の内容に一致する有効な記録を必要とします。
