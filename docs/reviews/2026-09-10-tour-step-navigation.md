# スマホの初期ツリーとツアーの階層

2026-09-10 / Codex

スマホの初期画面を、専用のシナリオ一覧から地図本体へ変更した。「現在」と7つのシナリオの列がスマホの幅に収まる配置にし、シナリオ名を読める倍率で開く。結果に続く接続も保持し、地図をドラッグして先へ進める。高さが足りない画面では下の分岐もドラッグで表示する。カードの選択、拡大縮小、画面外のカードを描画しない処理は既存の地図と共通である。

ツアーは一度に1ステップだけ本文を表示する。「次のステップ」は次の項目に進み、本文の途中までスクロールする動作は行わない。手動スクロールは現在の本文を読む操作に限定した。Enter・右矢印による移動も維持する。

シナリオの名前と番号を親として表示し、その内側にステップの選択欄と番号を置いた。同じシナリオの章をまたぐ場合は「次のステップ」、別のシナリオに入る場合は「次のシナリオ」に切り替わる。最後のシナリオからは「まとめへ」と表示する。日本語と英語の両方を更新した。

表示の順序や番号は読む順番を表す。因果データ、AND・ORの条件、科学的な説明、研究の出典は変更していない。スマホの配置も全体図のノードと接続を引き継いでいる。

## 確認

- `npm run check`：62テスト、型検査、lint、内容・翻訳・レビューの検査が成功。
- `npm run build`：GitHub Pages向け静的ビルドが成功し、11個の入口アセットを確認。
- ツアーの全シナリオについて、シナリオ内の番号、章の切り替え、シナリオの終端、まとめへの移動をテスト。
- スマホ配置では全体図のノード・接続IDの一致、7本の分岐、カード間隔と横幅、初期倍率をテスト。
- PC表示で、日本語の「次のステップ」が1項目進むことと、制御喪失の最後から「次のシナリオ」で人間による悪用へ進むことを確認。
- スマホ表示で、日本語・英語とも「次のステップ」で本文が1つだけ切り替わり、シナリオ番号を保ったままステップ番号が進むことを確認。
- スマホの初期ツリーを表示し、分岐カードからシナリオを開く操作と、地図のドラッグを確認。英語の「Present」を含め、実際のCSS表示幅291pxと354pxでカードの文字とページ横幅を点検した。

スマホ表示はブラウザーのビューポートを変更して確認した。実機のCPU性能やSafariでのタッチ操作を計測したものではない。今回の作業はローカルで完了し、公開は保留中である。
