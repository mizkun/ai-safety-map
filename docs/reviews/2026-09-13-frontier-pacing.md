## マップへの反映

- R2 / R3 と R1→R2、R2→R3、R3→R2：社内分析と著者のRSI開始の判断を追加。人が関わる循環と完全自律の後継開発を区別し、部分作業から工程全体や持続的加速へ飛躍しない。
- C3 / C3a1 / C3b と ASI→C3：新しい能力に試験・権限制限・停止手順が追いつくかを説明。外部の工程評価、停止を決める権限、共通基準と履行確認を対策の候補として追加。
- R4 と R0→R4：確保した時間を実装や評価に使う条件を追加。従来の限定された安全性実験の結果と、今回の政策提案を混同しない。
- 制御と能力開発のツアー：「なぜここで時間と競争の話をするか」が、能力の進歩、対策の準備、対処の遅れの順で読めるようにつなぐ。
- 制御シナリオの注目点：外部からの点検と、問題に対処する時間・権限を確保できるかを追加する。

競争が対応を遅らせるという説明は、原文を踏まえた条件付きの編集上の整理である。特定の事故の原因が競争だったと確定したものではない。新しい因果矢印は追加しない。開発が速くても適切な評価と停止が機能する場合、あるいは権限がなく危険な操作を実行できない場合を除外しない。

## 依存する説明の点検

44単位を点検した。C1・C2・C3のAND、見逃しと対処の遅れのOR、ASIなしでも起こり得る制御失敗、労働の自動化から所得・分配への追加条件を維持する。研究開発の社内指標を、他分野の能力や社会全体の自動化率に転用しない。

R2は引き続き間接的な根拠、R3の状態も従来どおり。R4の限られた評価の色や対策の表示は、従来の実験に依拠しており、今回の外部評価者の受け入れ表明を「実証済みの対策」へ加えていない。既存の観測の確認日を一括更新しない。

日英の出力を `review:reading` で生成し、変更した章の前後、項目を単独で開く詳細、出典・研究カードとの対応を確認した。RSIはその場で説明し、Amodeiの判断には立場を付記した。既存履歴の英訳はIDごとに保ち、新しい履歴だけを先頭に追加した。

点検記録の `reviewed` はCodexによる編集上の点検であり、独立した専門家による査読や科学的な真偽の証明ではない。既存の研究例は新規資料と整合するかを点検し、全件を今回新しく再調査したとは扱わない。
